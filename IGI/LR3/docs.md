### Переменные
Для **объявления переменной** в Python достаточно написать её название и присвоить ей значение:
```Python
number = 10             # имя_переменной = значение
```
Python - **динамическии типизируемый** язык, т.е. типы переменных определяются *непосредственно во время работы программы*. Однако хорошей практикой является указание типа переменной, ибо не всегда очевидно, как взаимодействуют те или иные сущности в коде. Указание типа переменной происходит после её названия, при этом сразу же за названием идёт двоеточие:
```Python
number: int = 10        # имя_переменной: тип = значение
``` 
Здесь мы для переменной `number` указали целочисленный тип данных `int`.

Следует отметить, что указание типа **не влияет** на значение переменной, ибо интерпретатор языка Python считает это указание как за метку. Поэтому указание типа в первую очередь полезно самому разработчику и убирает лишнюю путаницу в коде.

> Пример объявления переменной из лабораторной работы:
```Python
result: float = 0.0         # переменной result типа float присвоили значение
                            # 0.0 
``` 
### Операции с числовыми типами данных
В языке программирования Python как и в любом другом представлены основные арифметические операции: `+` (сложение), `-` (вычитание), `*` (умножение), `/` (деление), `//` (целочисленное деление), `%` (деление по модулю), `**` (возведение в степень).
Эти операции выполняются с двумя операндами (участниками операции). 

Обычно результат операции сохраняют в переменную. Чтобы это сделать нужно присвоить результат операции некоторой переменной:
```Python
a = 5
b = 7
result = a + b      # result = 5 + 7 = 12
```
Если мы хотим сохранить результат операции в один из операндов, то мы можем использовать арифметические операторы с присваиванием: `+=`, `-=` и др.
```Python
a = 4
b = 2
a /= b      # a = 4 / 2 = 2, результат сохранится в a.
```

> В лабораторной работе арифметическая операция с присваиванием [`arg /= 2.0`](task1.py#L18) используется для понижения аргумента логарифма. 

### Операторы ветвления
**Операторы ветвления** управляют потоком выполнения кода в зависимости от состояния данных. К операторам ветвления относятся:
- Условные операторы `if`,`elif`,`else`; 
- `match-case` оператор (аналог `switch-case`);
- Тернарный оператор.

Все операторы ветвления передают управление **блокам кода** - некоторый набор инструкций, который каким-либо образом обособлен и воспринимается как единое целое. 
В Python блоки кода выделяются с помощью табуляции (4 пробела):
```Python
# Внешний блок кода
...
...
    # Внутренний блок кода
    ...
    ...
...
```

Оператор `if` передаёт управление блоку кода, если указанное в нём условие выполняется (возвращается `True`):
```Python
a = 10
if a > 7:           # 10 > 7 == True -> управление переходит коду 
    a -= 2          # после двоеточия
```
Оператор `elif` передаёт управление блоку кода, если указанное в нём условие выполняется, при этом условие в предшедствующем операторе `if` не выполнилось:
```Python
a = 10
if a > 12:          # 10 > 12 == False -> идём дальше
    a -= 2
elif a > 8:         # 10 > 8 == True -> управление переходит коду
    a -= 3          # после двоеточия
```

Оператор `else` передаёт управление блоку кода, если условия во всех `if` и `elif` не выполнились.

Оператор `match-case` передаёт управление тому блоку кода (кейсу), который совпал по значению с передаваемым в `match` значением, и после чего выходит из конструкции автоматически:
```Python
match num:      
    case 5:             # если num = 5, то выполняется этот case
        print("ok")     # после чего мы выходим из match-case
    case 7 | 10:        # если num = 7 или num = 10
        print("hm")
    case _:             # если ничего из предложенного, то
        print("nope")   # выполняется этот case (default-case)
```

**Тернарный оператор** является однострочной записью `if-else` и может использоваться, например, для инициализации переменной
```Python
c = 2
b = 5

# {выражение, если True} if {условие} else {выражение, если False} 
a = b if b > c else c   # a = b, т.к. b > c
``` 
> В задании `if` используется для проверки значения аргумента логарифма. В случае, если он не удовлетворяет области определения логарифма, возбуждается исключение.

### Операторы циклов
**Операторы циклов** используются для повторного выполнения определённых участков кода. К ним относятся операторы:
- `while` 
- `for-else`

Оператор `while` выполняет блок кода до тех пор, *пока выполняется требуемое условие*:
```Python
while условие:
    выполняемый код
    ...
```

Оператор `for-else` выполняет блок кода *определённое количество раз*. Блок `else` выполнится в случае, если цикл не прервётся с помощью операторов управления `break` и `return`:
```Python
for i in range(1, 10):              # range возвращает список
    i *= 2                          # элементов от 1 до 10
else:                               # блок else выполнится 
    print("ended without breaks")   # т.к. в основном блоке не
                                    # было прерываний
```

Оператор `break` используется для принудительного выхода из операторов ветвления и циклов.

### Функции
**Функцией** называется набор действий, использующий исходные данные для получения конечного результата. Формально функцию можно описать следующим выражением
$$f: A \rightarrow B$$
При программировании в **функции** обычно заносят код, который можно переиспользовать в дальнейшем.

Для определения функции в Python используется ключевое слово `def`. Дальше указывается название функции и в скобках список её параметров:
```Python
def func(x, y)          # func - название, x,y - параметры
```
Строка кода, включающая в себя название функции и её параметры, называется **сигнатурой (прототипом)** функции. 

Каждая функция обязательно должна вернуть результат её работы. Для возврата значения из функции используется ключевое слово `return`. Однако, если разработчик не хочет возвращать из функции какое-то значение, то `return` указывать необязательно.
```Python
def func(x, y):
    # В Python для блока кода функции нужно использовать табуляцию
    print("Аргумент x = ", x)   
    print("Аргумент x = ", y)
    return x**2 + y**3      # возврат значения

a = func(1, 2)              # a = 1 + 2^3 = 9         
```
Аналогично переменным, для функции желательно указывать типы принимаемых параметров и возвращаемый тип:
```Python
# Если нужен возврат значения из функции:
def func(x: int, y: int) -> int

# Или, если мы не хочем возвращать значение:
def func(x: int, y: int) -> None
```
#### Параметры по умолчанию
Параметрами по умолчанию являются параметры, которые мы явно не передаём в функцию и они инициализируются по умолчанию (отсюда и название).
```py
def counter(n: int = 5) -> None         # указали значение 
                                        # по умолчанию для параметра n - 5

counter(3)                              # можно передать другой параметр
counter()                               # можно вызвать без параметров
                                        # тогда вызовется counter(5)
```
Важно подметить, что параметры по умолчанию должны быть указаны последними в списке параметров!
```py
def func(x, y = 5): # нет ошибки

def func(x = 5, y): # ошибка
```

### Коллекции
**Коллекциями** называются некоторые хранилища для групп объектов(зачастую однотипных). Коллекции поддерживают:
- проверку на вхождение элемента `in` \ `not in`
- длину (`len()`)
- возможность итерирования (прохождения) по ней. Поэтому зачастую коллекции называют **итерируемыми объектами**.

**Последовательностями** называются *упорядоченные* коллекции, поддерживающие доступ к её элементам по индексу. Примеры:
- `list()` - список
- `tuple()` - кортеж
- `str()` - строка
- `range()` - диапазон

### Списки
Представлены типом данных `list`. Для инициализации списка используется литерал `[]` (квадратные скобки). В списках могут храниться элементы различных типов, например
```py
a = [1, True, "text", [2, 5]]
```

Тип `list` предоставляет ряд методов для работы со списками. Основные из них:
- `append(x)` - добавление элемента x в конец списка
- `insert(index, x)` - вставка элемента x на позицию index.
- `remove(x)` - удаление элемента x из списка, если таковой имеется
- `pop(index)` - извлечение элемента на позиции index из списка
- `extend(iterable)` - добавление в конец списка элементов, находящихся в коллекции iterable  
- `clear()` - очистка списка (удаление всех его элементов)
- `sort(key=None, reversed=True)` - сортировка списка в соответствии с правилом key в порядке reversed. Отличается от `sorted()` тем, что он в отличие от него модифицирует *текущий* список, а не создаёт новый.
